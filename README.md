# 《写给爸爸妈妈的一封长信》

这是一个由姐姐写给爸爸妈妈、记录一家四口的纯静态家庭叙事网站，可直接部署到 GitHub Pages。

## 本地查看

直接打开 `index.html` 即可浏览；为获得与线上一致的加载体验，也可用任意静态文件服务器预览。

## GitHub Pages 部署

1. 在 GitHub 新建一个公开仓库。
2. 将本文件夹内的全部内容上传到仓库根目录（不要只上传 `index.html`）。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待部署完成，GitHub 会显示公开网址。

## 素材说明

- 选用 10 张生活照片作为叙事依据；叙事人物为爸爸、妈妈、弟弟和姐姐。
- 公开版本中的真人照片均已转换为非写实手绘漫画，并压缩为 WebP；原始照片未移动、未覆盖。
- 原聊天截图已改成匿名文字卡片，公开目录不包含群名、头像或聊天界面原图。
- 背景音乐仅使用素材目录中的《轻高古典钢琴音乐主题》。
- 素材没有可用 EXIF 日期，因此叙事只使用“那时候 / 后来 / 直到现在”，没有虚构年份、地点或具体事件。
